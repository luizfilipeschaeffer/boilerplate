# Publicar listing no marketplace central

## Objetivo
Registrar módulo/integrador em `MarketplaceListing` com entitlements e preço.

## Quando usar
Após aprovação de publicação comunitária ou release de módulo oficial.

## Entradas
- externalId, kind, currentVersion, minimumPlatformVersion
- entitlementsRequired, pricingModel

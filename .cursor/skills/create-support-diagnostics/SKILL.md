# Diagnósticos de suporte por módulo

## Objetivo
Coletar contexto técnico sanitizado para tickets vinculados a módulos.

## Quando usar
Ao implementar handlers de suporte ou botões "Reportar problema" no módulo.

## Incluir
- moduleId, versão instalada, platformVersion
- lastMigrationStatus, healthStatus

## Excluir
- PII, valores financeiros, credenciais
